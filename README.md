# Shutdown Timer

Таймер выключения для Windows. Ставишь время, уходишь по делам, а компьютер выключается сам.

Главное отличие от обычного `shutdown /t`: пока идёт отсчёт, программа не даёт Windows уйти в сон
по бездействию, иначе таймер встаёт и выключения не происходит.

## Запуск из исходников

    pip install -r requirements.txt
    python src/main.py

## Сборка в exe

Запусти `build.bat` на Windows. Готовый файл появится в `dist\ShutdownTimer.exe`.

## Ограничения

Защита от сна работает только пока программа открыта.
